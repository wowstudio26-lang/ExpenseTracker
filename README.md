# Expense Tracker

A mobile-first Android expense tracker with an offline data store and home-screen widget.

## Current V1
- Dashboard with monthly total
- Add expenses
- Expense list and delete
- INR formatting
- Initial sample data: ₹50,950
- Home-screen Glance widget
- Widget refresh after transactions
- GitHub Actions APK build

## Build
Use the GitHub Actions workflow named **Build Expense Tracker APK**. The resulting debug APK is published as a workflow artifact.
